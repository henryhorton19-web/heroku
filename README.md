# arb

Personal reselling tool. Vinted buy-side, eBay sell-side, one ledger.

```
Vinted listing → what's it worth on eBay? → buy → list well → price right → sold → ledger
```

**Status: Step 0 (scaffold) complete.** Steps 1–4 not started. See `SPEC.md` for the
current module contract and `CONTEXT.md` for standing policy.

---

## Quickstart

```bash
uv sync                     # install, locked
uv run arb db upgrade       # create the database
uv run arb doctor           # what is configured, what is missing
```

`doctor` runs with no credentials at all. Missing keys mean a later step is
unavailable, not that the tool is broken.

### Reference data

```bash
git clone --depth 1 https://github.com/0AlphaZero0/Vinted-data.git /tmp/vinted-data
uv run arb load-refdata --data-dir /tmp/vinted-data/DATA
```

Loads ~3.7k rows: 2,535 brands, 796 catalog nodes, 285 sizes, 28 colours, 5 statuses.

Two things to know about this data before you trust it:

- **It is a `vinted.fr` capture.** Titles are French and there is no GB in
  `country.json`. Join on `id` or `code`; never on `title`.
- **The brand list is a seed, not a census.** Stone Island, Barbour, Patagonia,
  Arc'teryx, Berghaus and Columbia are all absent. Use it as a normalisation lookup.
  **Never as a brand allowlist** — you would filter out exactly the stock worth buying.

### Configuration

Copy `.env.example` to `.env`. Everything is prefixed `ARB_`. Nothing in `.env`,
`ebay_rest.json` or `arb.db` is ever committed; the repo is public and that is not a
soft rule.

## The gate

Most code here is agent-written and will not be reviewed line by line, so quality
rests on a deterministic gate rather than on review.

```bash
uv run ruff check . && uv run ruff format --check .
uv run mypy
uv run python scripts/guard.py
uv run pytest
```

`pre-commit install` mirrors this locally. GitHub Actions is the verdict.

`scripts/guard.py` enforces what lint and types cannot: no suppressions
(`type: ignore`, `noqa`, `pragma: no cover`, `nosec`), no hand-written `Any` in
`src/`, the 4,000-line authored budget, and `.gitignore` coverage of the three
never-commit files.

**Never weaken the gate to make something pass.** If a rule genuinely cannot be
satisfied, stop and escalate. Two exceptions exist today; both are documented at the
site with the reasoning and the empirical check behind them.

## Constraints that bite

**eBay apparel sizing is enforcing now.** Size and Condition are required on new
fashion listings; non-standard values are blocked or held and are not indexed by
search. Step 4 must validate against cached Taxonomy enums *before* publish.

**`rembg` model licence.** Always pass `-m u2net_cloth_seg` explicitly. The default
`bria-rmbg` weights require a paid agreement for commercial use.

**Vinted automated access is against their terms.** Contract, not criminal; the
realistic exposure is the account you use. Keep the trading account separate from
anything you cannot lose. Rate limiting defaults to 1.5 req/s, capped at 2.0.

**Excluded throughout:** reposting to defeat duplicate detection, discount-code
generation, ACO botting, watermark removal, fingerprint spoofing, proxy rotation to
defeat IP blocking.
